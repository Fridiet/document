## 업로드 주의사항

- 공개 저장소이므로 **서명 없는 버전만** 업로드합니다.
- 서명·도장·연락처 등 공개하면 안 되는 개인정보를 확인하고 제거합니다.
- API 키, 비밀번호, 인증 토큰, DB 접속 정보가 문서나 캡처에 포함되지 않도록 확인합니다.
- 파일을 교체한 뒤에도 과거 Git 이력에 남을 수 있으므로 업로드 전에 확인합니다.
